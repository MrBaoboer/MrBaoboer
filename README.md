### 需求洞察

捕捉到年轻职场用户对“工作时间—工资回报”实时感知的情绪需求：工资一个月到账一次，劳动却每一分钟都在发生

借助 Codex 和 Claude Code 独立开发了一款轻量优雅的「实时工资」小软件，根据薪资和上下班时间动态计算每一秒的收入增长，让劳动时间价值可视化

### 产品实现

基于 Tauri 2 + Vue 3 构建，桌面版提供迷你悬浮窗，网页版全面适配 PC 端与移动端，随时查看“已经挣了多少钱”

薪资数据只存本地，无账号、无遥测：最敏感的数据，用最克制的方式处理

### 发布增长

独立完成产品官网部署、CI / CD 工作流搭建与 Product Hunt 首发，三个月迭代 66 个 Release

GitHub 下载量 **1800+** 次、**55** Stars，获抖音精选 AI 博主推荐，已申请软件著作权

跑通“需求洞察 — 功能设计 — 开发测试 — 发布增长”的完整闭环

  <img width="34%" alt="氛寸 FenCun：今日推荐（浅色）" src="assets/fencun-1.webp">

### 需求洞察

别人帮你挑香水，氛寸帮你用好香水：国内产品都停在“买”这一步，“买之后每天怎么用”没有人做

一个基于实时天气 × 出席场合的「用香决策」Agent，从你已有的香柜里给出今天喷哪瓶、喷多少、喷在哪、能留多久，并解释为什么

### 产品实现

基于 Next.js + React + TypeScript 构建，已上线可用

将 13.2 万款社区香水数据筛至 3.67 万款，热度前 1500 款完成全中文精选；140 余条用例守住对用户说出口的每一条承诺

### 工程思路

决策权给规则引擎，表达权给大模型：打分、喷量与裁决全部由确定性规则计算，可解释、可复现、可降级

DeepSeek 只负责解析自然语言场景与生成话术，输出经 schema 校验与数字白名单把关，异常即整段回退模板
