### 薪跳 PayDance

<sub>Vibe Coding 独立产品开发者 · Tauri 2 + Vue 3 + TypeScript · 2026.05 – 2026.08</sub>

[![Stars](https://img.shields.io/github/stars/MrBaoboer/PayDance?style=flat-square)](https://github.com/MrBaoboer/PayDance/stargazers)
[![Downloads](https://img.shields.io/github/downloads/MrBaoboer/PayDance/total?style=flat-square)](https://github.com/MrBaoboer/PayDance/releases)
[![Release](https://img.shields.io/github/v/release/MrBaoboer/PayDance?style=flat-square)](https://github.com/MrBaoboer/PayDance/releases/latest)

**让每一秒的收入增长都看得见。** 捕捉到年轻职场用户对「工作时间—工资回报」实时感知的情绪需求，借助 Codex 和 Claude Code 独立开发了一款轻量优雅的「实时工资」小软件，根据用户的薪资和上下班时间动态计算每一秒的收入增长，让劳动时间价值可视化。

- **独立开发** — 基于 Tauri 2 + Vue 3 构建：网页版全面适配 PC 端与移动端，Windows 桌面版提供可置顶的迷你悬浮窗，支持随时查看「已经挣了多少钱」；本地优先，不上传任何数据
- **独立发布** — 独立完成产品官网部署、CI / CD 工作流搭建、Product Hunt 首发，已申请软件著作权
- **增长结果** — GitHub 下载量 1600+ 次，获 50+ Stars，获抖音精选 AI 博主推荐；跑通「需求洞察—功能设计—开发测试—发布增长」的完整闭环

### 氛寸 FenCun

<sub>用香决策 Agent · Next.js + TypeScript + DeepSeek · 2026</sub>

[![Stars](https://img.shields.io/github/stars/MrBaoboer/FenCun?style=flat-square)](https://github.com/MrBaoboer/FenCun/stargazers)

**别人帮你挑香水，氛寸帮你用好香水。** 站在香柜前，缺的从来不是香水，而是「今天用哪瓶、怎么用得恰到好处」的判断。氛寸不做导购、不做调香，只解决这一个每天真实发生的决策：从你已有的香柜出发，结合实时天气与出席场合，告诉你喷哪瓶、喷多少、喷在哪、能留多久，以及为什么。

- **产品判断** — 只给区间与档位，拒绝伪精确；真不合适就明确说「今天不建议这瓶」，不迁就用户
- **架构取舍** — 决策权在确定性规则引擎（可解释、可单测、本地毫秒出结果），表达权在 LLM：DeepSeek 只负责听懂自然语言场景、把事实翻译成人话；输出经数字白名单校验，模型超时也不白屏
- **反馈闭环** — 每次推荐都能被评价与修正，个人偏移按瓶收敛；香历自动记录每一次用香

[在线体验](https://fencun.vercel.app) · [源码](https://github.com/MrBaoboer/FenCun) · [产品方案](https://github.com/MrBaoboer/FenCun/blob/main/docs/%E6%B0%9B%E5%AF%B8-%E4%BA%A7%E5%93%81%E6%96%B9%E6%A1%88.md)
